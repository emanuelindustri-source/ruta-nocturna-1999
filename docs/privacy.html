Privacidad

Ruta Nocturna: 1999 es un juego single-player sin cuentas, sin publicidad y sin telemetría. Esta página describe qué datos existen en el proyecto y en la web.

1. El juego

El juego guarda localmente, en el almacenamiento privado de la aplicación:

  • Partidas manuales y autoguardados.
  • Ajustes gráficos, audio, controles y accesibilidad.
  • Fotografías tomadas con la cámara interna del juego.
  • El último reporte de error y los reportes locales de QA.

Estos datos no se envían automáticamente a ningún servidor. El usuario puede borrarlos desinstalando la aplicación o eliminando los archivos locales.

2. Actualizaciones

La build distribuida por GitHub puede consultar la API pública de GitHub Releases para comprobar si existe una versión nueva. Esa consulta no incluye datos de la partida. La build de Google Play no usa ese actualizador y abre la ficha de Play Store cuando corresponde.

3. Web

Esta página es estática y se publica con GitHub Pages. No usa cookies propias, analítica, píxeles publicitarios ni formularios. GitHub puede registrar la visita según su propia política. Los enlaces a GitHub se abren fuera de la página.

4. Caja negra

El juego puede generar un reporte de error local con versión, plataforma, estado de la región, clima, vehículo y últimas líneas de log. El reporte se guarda en el almacenamiento privado de la aplicación y no se sube automáticamente. Si el jugador lo comparte, es una acción voluntaria.

5. Menores y contenido

El juego contiene terror psicológico, violencia sobrenatural y temas para adultos. No está diseñado para niños pequeños. No hay compras dentro de la aplicación ni cajas de botín.

6. Terceros

  • Godot Engine: motor del juego.
  • GitHub: alojamiento del código, releases y Pages.
  • OpenStreetMap: datos geográficos con atribución ODbL cuando se usen.

No se integran SDK de publicidad, analítica o redes sociales.

7. Cambios

Esta política se actualizará antes de una publicación en Google Play o antes de introducir cualquier forma de red, cuenta o telemetría. La fecha de actualización aparecerá al inicio.

8. Contacto

Para asuntos de privacidad o para reportar un problema, abre un issue en el repositorio público:

github.com/emanuelindustri-source/ruta-nocturna-1999/issues
