# Dirección de arte de interfaz

**Fuente:** 39 conceptos visuales de 2730×1536, únicos, generados con Gemini, más
fotografías de referencia. **No son assets ni capturas de producto.**

## Elementos adoptados

- Paleta nocturna: verde petróleo profundo, ámbar de instrumentos, hueso, óxido,
  rojo de emergencia y cian apagado.
- Sensación CRT/analógica de finales de los noventa, sin sacrificar legibilidad.
- Interfaz lateral de módulos para la pausa: sistema, garaje, ruta, inventario,
  bestiario, logros y estado.
- Brújula de carretera, mapas de papel, bitácora y radio AM/FM.
- HUD de conducción con combustible, temperatura, odómetro, fatiga y dinero en
  bolívares de 1999.
- Modo cámara/álbum con filtro de película y anotaciones de fecha.
- Menús con navegación D-Pad y foco visible; la pantalla táctil no es un teclado de
  botones.
- Uso de las ilustraciones conceptuales para vestuario, clima, vegetación y
  composición de escenas; el modelo final se genera desde cero.

## Elementos rechazados o corregidos

| Idea del concepto | Decisión |
|---|---|
| Rejillas de 20–25 botones táctiles | Rechazado. Interacción contextual 3D con un botón de acción |
| Logos Chevrolet, PDV, Google Play Games | No usar sin licencia; sustituir por marcas originales |
| “LibGDX / OpenGL ES 3.2” | Incorrecto; el motor es Godot 4.7.2 |
| “Roguelike” y “cinco noches” | Fuera del alcance aprobado |
| Monetización y tienda | No aprobado; no implementar |
| Entidades extra no validadas | Archivar; no agregar al canon sin decisión |
| UI táctil sobre el volante y tablero | Rechazada por saturación; se usan objetos del mundo |
| Capturas generadas por IA como screenshots de tienda | Rechazado; las capturas finales serán del juego real |

## Reglas de UI final

1. Máximo siete controles táctiles persistentes.
2. Ningún control de cabina se duplica en la pantalla.
3. El objeto físico se resalta al mirarlo o tocarlo.
4. La mano IK acompaña la interacción; el feedback no es solo un cambio de icono.
5. Todo menú funciona con D-Pad, gamepad, teclado y táctil cuando corresponda.
6. El texto visible pasa por localización y validación de glifos.
7. La accesibilidad permite alto contraste, fuente para dislexia, tamaño de texto,
   reducción de destellos y movimiento.
8. La estética no justifica ilegibilidad ni fuentes que no cubran los 11 idiomas.

## Material de tienda

- Los iconos y banners se generarán desde arte original del proyecto.
- Las capturas 1920×1080 deben ser gameplay real.
- Una captura 1080×1920 solo se usará si existe una vista vertical real (menú o
  álbum); en caso contrario será arte promocional etiquetado como tal.
- Los conceptos Gemini no se publicarán como screenshots.
- Las imágenes se validarán por tamaño, zona segura y legibilidad.
